## Was sind KI-Arbeitsprofile?

::::: karten

::: karte
**Projekte** sind Ordner im KI-Tool, in denen Dateien und Anweisungen zu einem Thema liegen.

*Beispiel: Mein Projekt „KI-Lernreise“ kennt alle Info-Sheets und Folien und hilft bei Mails, LinkedIn-Posts und Konzeptfragen.*
:::

::: karte
**Assistenzen** sind „Unterbots“ mit Rolle, Infos, Abläufen und Rückfragen, die dir eine wiederkehrende Aufgabe abnehmen.

*Beispiel: „Du bist Veranstaltungsplaner\*in und erstellst mit mir eine Checkliste. Frag zuerst nach Datum und Ort.“*
:::

::: karte
**Skills** sind kleine Anweisungen, die für viele Arbeitsprozesse gelten. Sie aktivieren sich selbst, wenn Triggerwörter auftauchen.

*Beispiel: Gender-Regeln, die automatisch greifen, sobald du einen Text schreibst.*
:::

:::::

:::: karten

::: rahmenkarte
**(Echte) Agentische KI** sind komplexe Systeme, die selbst Strategien entwickeln und Tools eigenständig einsetzen. NUR für Fortgeschrittene und bezahlpflichtig, z. B. **ChatGPT Work** und **Claude Cowork**. Mehr dazu: [www.juliajunge.de/agentische-ki](https://www.juliajunge.de/agentische-ki) *Verwirrend: Copilot, Langdock und andere nennen auch einfache Assistenzen „Agenten“.*
:::

## Schritt für Schritt zur eigenen Assistenz

<div class="schritte-quer">

::: schritte
1. ### Entdecke Use Cases
   Welche Aufgabe wiederholt sich? Was fragen Kolleg*innen dich ständig? Wo denkst du: „Das müsste mir doch KI abnehmen können…“?

2. ### Plane mit dem Canvas
   Kläre Aufgabe und Ziel, wer die Assistenz nutzt, welchen Input sie bekommt, welche Zwischenschritte sie macht, was herauskommen soll und welche Regeln gelten.

3. ### Lass die KI den Prompt schreiben
   Kombiniere einen Start- und einen Ziel-Baustein aus dem Prompt-Baukasten. Die KI schlägt dir auch vor, welches Wissen und welche Beispiele du hinterlegen solltest.

4. ### Testen, teilen, verbessern
   Speichere das Ergebnis als Assistenz, Projekt oder Skill. Teste es im Alltag, teile es mit anderen und verbessere es Schritt für Schritt.
:::

</div>

<div class="anleitung-unten"><div class="tipps-box"><h3>4 Tipps, damit es schneller geht</h3><ul><li><strong>Erst planen, dann prompten:</strong> Fülle zuerst das Canvas aus und gib es mit Start-Baustein B an die KI. So musst du weniger erklären.</li><li><strong>Reden statt schreiben:</strong> Beantworte die Fragen der KI per Spracheingabe. So erzählst du von selbst mehr Details.</li><li><strong>Frag, was fehlt:</strong> Lass dir von der KI sagen, welche 3 Infos sie braucht, um die Aufgabe zu erledigen.</li><li><strong>Nach guten Arbeitssessions zusammenfassen:</strong> Mit Start-Baustein C machst du aus einem gelungenen Chat eine neue oder bessere Assistenz.</li></ul></div><img src="drache-spirale.png" alt="Drachen steigen auf einer Spirale nach oben, vom ersten Entwurf bis zum fertigen Ergebnis"></div>

## Prompt-Baukasten: Lass dir von der KI helfen

Kopiere **einen Start-Baustein** und **einen Ziel-Baustein** untereinander in einen neuen Chat. Start C fügst du am Ende eines guten Chats ein.

<div class="baukasten baukasten--start">

<div class="baustein">

### Start A: Ich fange neu an

```
# Aufgabe
Hilf mir zu klären, was meine KI-Assistenz tun soll und welche Infos sie braucht oder erfragen soll.

# Regeln
Stelle immer nur eine Frage auf einmal, höchstens 5. Erfrage auch nötiges Fachwissen oder biete eine Recherche an. Die letzte Frage ist, ob die KI noch etwas Besonderes wissen soll.
```

</div>

<div class="baustein">

### Start B: Ich habe das Canvas ausgefüllt

```
# Aufgabe
Hier ist mein ausgefülltes Canvas für eine KI-Assistenz: [Text einfügen oder Foto hochladen]

# Regeln
Prüfe es auf Lücken und Widersprüche. Stelle höchstens 3 Rückfragen, immer nur eine auf einmal.
```

</div>

<div class="baustein">

### Start C: Ich hatte einen guten Chat

```
# Aufgabe
Fasse den Arbeitsprozess in diesem Chat zusammen: Ziel, Schritte, nötige Infos und Rückfragen, meine Korrekturen, Ergebnis.

# Regeln
Übernimm nur, was sich bewährt hat. Mach aus meinen Korrekturen Regeln. Stelle höchstens 3 Rückfragen, immer nur eine auf einmal.
```

</div>

</div>

<div class="baukasten-plus" aria-hidden="true">+</div>

<div class="baukasten baukasten--ziel">

<div class="baustein">

### Ziel 1: Instruktion für CustomGPT, Projekt oder Agent

```
# Output
Recherchiere zuerst im Internet aktuelle Infos dazu, was gute Assistenz-Prompts ausmacht. Erzeuge dann eine kopierfähige Instruktion in Raw Markdown mit höchstens 7.500 Zeichen. Schlage vor, welche Dokumente ich als Wissensbasis oder Beispiele hinterlegen sollte.
```

</div>

<div class="baustein">

### Ziel 2: Skill-Datei

```
# Output
Recherchiere zuerst im Internet aktuelle Infos dazu, wie gute Skills aufgebaut sind. Erzeuge dann eine Skill-Datei SKILL.md zum Herunterladen: oben name und description (wann der Skill sich aktivieren soll, mit Triggerwörtern), darunter knappe Anweisungen. Schlage vor, welche Vorlagen oder Beispiele ich als zusätzliche Dateien beilegen sollte.
```

</div>
